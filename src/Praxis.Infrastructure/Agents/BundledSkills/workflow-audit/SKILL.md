---
name: workflow-audit
description: "Find repetitive workflows worth packaging from task summaries, handoffs and existing procedures."
---

Use recent task evidence first, then memory and existing skills. Group by inputs, procedure and stop condition, not by project names. Count distinct episodes and avoid double-counting interrupted chats. Recommend a skill only for a stable high-value pattern, a specialist only for an independently scoped role, an automation only for a defined event/cadence. Explain skipped items and the evidence needed to reconsider.
