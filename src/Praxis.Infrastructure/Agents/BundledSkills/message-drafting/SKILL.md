---
name: message-drafting
description: "Draft an email, update, request or sensitive message in the owner's voice for review."
---

Determine recipient, purpose, desired action and tone. Use prior writing samples only if supplied or authorized. Put the ask early, give only relevant evidence and use an explicit subject when appropriate. Remove sensitive details that the recipient does not need. If facts or addresses are missing, identify them outside the draft. Never claim a message was sent without a permitted send result.
