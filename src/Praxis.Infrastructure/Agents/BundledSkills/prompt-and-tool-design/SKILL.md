---
name: prompt-and-tool-design
description: "Design or review an agent prompt, tool contract, or evaluation plan with explicit permission boundaries."
---

State the task, trusted instruction source, data input and permitted effects. Define a clear schema for tool arguments, validate untrusted fields in application code and require bounded output. Include success, denial, malformed input and prompt-injection checks. Version the change and measure task outcomes; never rely on prompt wording to enforce permissions.
