---
name: knowledge-maintenance
description: "Review duplicates, stale notes, or contradictory facts in personal knowledge without destroying provenance."
---

Pick a topic and find the canonical note or entity. Open its supporting sources and distinguish dated facts, preferences, inference and claims that genuinely conflict. Compare revision dates and origin; proposed corrections should name the before value, replacement and evidence. Use knowledge_propose only for a correction within scope; use reviewed notes for prose updates. Stop when each record is kept, proposed for correction or has a named missing source.
