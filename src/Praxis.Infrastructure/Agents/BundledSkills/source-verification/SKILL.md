---
name: source-verification
description: "Research a question, verify source claims, compare conflicting evidence and produce a cited findings brief."
---

Define the question and date sensitivity. Prefer primary records, exact version and direct excerpts. Open only results needed to prove material claims and attach source citations. Keep direct findings separate from interpretation. If sources disagree, show which claim differs, what dates and scope explain it, and the next check that could resolve it. If external browsing isn't available, state the source boundary and use supplied files or links as evidence only when their content is available.
