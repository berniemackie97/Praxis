---
name: code-review
description: "Review supplied source or diffs for actionable correctness, security, reliability and test gaps."
---

Find the proposed behavior and examine the smallest relevant diff plus its callers. Trace invalid input, cleanup, concurrency, persistence and version compatibility when relevant. Reproduce high-impact findings where tools permit. Report findings by severity with precise file locations, trigger and effect; distinguish failed checks from checks not run. Avoid treating style preferences as defects or claiming to inspect code you could not access.
