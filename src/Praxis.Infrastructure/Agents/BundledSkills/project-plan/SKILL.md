---
name: project-plan
description: "Turn a project or product goal into sequenced small tasks with dependencies and acceptance tests."
---

Define one intended outcome, what is in scope and the current baseline. Reuse existing issues before proposing new work. Specify deliverables and observable acceptance, the prerequisite for each task, owner if given and the next ready slice. Separate blocking dependencies from useful follow-ups. Capture unresolved constraints as questions rather than inventing dates or completion.
