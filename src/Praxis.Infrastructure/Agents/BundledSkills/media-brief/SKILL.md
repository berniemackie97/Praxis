name: media-brief
description: "Create an image, video, animation or mascot brief with explicit deliverables and quality checks."
---

Define scene, subject, style, dimensions, duration or states, and required output format. Use references to anchor visual details; avoid sending original private media to unapproved services. Specify what to keep on edits and how to evaluate the result. Use media tools only if available and authorized; otherwise return a production-ready brief and identify what still needs generation or rendering.
