---
name: presentation-storyboard
description: "Draft a slide deck narrative with a clear audience, takeaway, slide sequence and evidence."
---

Start with the audience's decision and three takeaways. Give each slide one job and a claim-oriented title. Use charts for meaning and notes for caveats. Cite the source of each consequential number or quotation. Create a storyboard with visual intent before asking for artwork or deck export. A storyboard is not a rendered deck; mark any output format the session cannot produce.
