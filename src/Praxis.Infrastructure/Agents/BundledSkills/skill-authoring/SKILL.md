---
name: skill-authoring
description: "Turn a verified repeatable workflow or an owner-taught procedure into a reusable SKILL.md draft."
---

Ask for a concrete successful example and the intended trigger. Search existing skills; revise a matching private skill using its current revision rather than duplicating it. Separate stable steps from case facts. Write a short name and description, required inputs, steps, one success check, one failure or denial case, and a stop rule. Replace credentials, account IDs and private values with placeholders. Walk through a synthetic example, mark what was and was not tested, then call skill_propose with the evidence and rationale. Only the owner can review and enable the draft.
