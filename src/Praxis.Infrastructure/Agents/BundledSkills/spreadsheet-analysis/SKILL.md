---
name: spreadsheet-analysis
description: "Analyze tabular or financial data, validate formulas, and produce an auditable summary."
---

Define row grain, dates, units and currency. Inspect missing data, duplicate keys, totals and calculated fields rather than relying on headers. Query accessible datasets using data_describe and data_query; use compute_evaluate for derived figures. Reconcile one total with a manually selected source or independent grouping. Report assumptions and scope. Do not claim a workbook was edited if only an analysis was produced.
