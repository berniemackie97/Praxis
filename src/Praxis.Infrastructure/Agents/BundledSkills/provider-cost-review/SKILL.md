---
name: provider-cost-review
description: "Investigate model usage, latency, routing or capability, and compare local and hosted options."
---

Pin task type, provider, model and time period. Compare like-for-like requests using logged tokens, calls, latency and output checks; missing metrics are unknowns. Separate limits, fallback routes and output quality. Test one low-risk sample locally where possible. Recommend the least expensive route that meets the evidence bar without editing routing or disclosure settings unless asked and permitted.
