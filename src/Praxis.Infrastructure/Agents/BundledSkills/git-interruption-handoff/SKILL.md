---
name: git-interruption-handoff
description: "Prepare or resume a Git checkpoint when a chat ends, usage runs low, or the owner continues locally."
---

Record the actual repository, worktree, branch, HEAD, active merge or rebase and scoped staged/unstaged/untracked changes. Preserve unrelated edits. Use current Git evidence over older summaries. Match any authorized draft checkpoint to its remote, base and exact published SHA; re-read after interruption before trying again. List tests with the state they actually covered, what remains and the first next command. If Git access is unavailable, ask for the minimal status output and prepare the handoff without claiming to push.
